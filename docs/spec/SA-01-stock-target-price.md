# SA-01：股票目標價（Stock Target Price）畫面規格

## 1. 功能簡介
針對單一股票，依歷史本益比（PER）／股價淨值比（PBR）估值，計算出 6 個目標價位
（便宜～爆炸貴），並提供目前成交價與目標價的差距、預估填息回本年數等指標，協助使用者
判斷買賣時機。

## 2. 計算基準（本文件補充定義，原始需求未列細節，已與使用者確認/建議如下）

- **股價基準**：不做除權息還原，但依用途分兩種取法（決策見 DEC-4、DEC-10）：
  - 年度最高／最低價（用於 10年高/低、前目標價出現、PER/PBR 的低/高估算）→ 當日**盤中實際最高/最低價**
  - 年度平均價（用於 PER/PBR(均)、年度殖利率換算）→ **收盤價**
- **統計時間窗**：「10年」統計一律指近 10 個完整曆年（不含當年度尚未結束的資料）。
- **年度 PER／PBR 定義**：
  - 年度 PER(低) = 該年度最低股價 ÷ 該年度 EPS；年度 PER(高) = 該年度最高股價 ÷ 該年度 EPS；年度 PER(均) = 該年度平均股價 ÷ 該年度 EPS
  - 10年平均最低 PER = 近10年「年度 PER(低)」之平均；10年平均 PER = 近10年「年度 PER(均)」之平均；10年平均最高 PER = 近10年「年度 PER(高)」之平均
  - PBR 比照辦理，以 BPS 取代 EPS
- **年度殖利率定義**：直接採用 FinMind TaiwanStockPER 的 dividend_yield 官方欄位，先算年度平均，再取近10年平均（決策見 DEC-11），不再自行用現金股利÷均價手算。
- **數值精度**：價格建議顯示到小數點後 2 位、百分比顯示到小數點後 2 位（待前端規格確認，見開放問題）
- **EPS／BPS 平均計算範圍**：僅採用**已完整公告的年度數字**，不納入尚未滿一年的最新一期（TTM）（決策見 DEC-9）

## 3. 欄位規格

### 3.1 設定類欄位（使用者輸入/選擇）

| 欄位 | 說明 | 型別/選項 |
|---|---|---|
| 代號 | 股票代號 | 文字 |
| 名稱 | 股票名稱 | 由代號帶出 |
| 產業別 | 股票所屬產業分類，由代號帶出；UI 顯示於股票名稱旁的小字，非獨立分析欄位（決策見 DEC-16） | 由代號帶出 |
| 投資策略 | 使用者自由備註，記錄**整體投資邏輯/長期計畫**（與「設定備註」是不同功能的獨立欄位，見 DEC-6） | 純文字 |
| **EPS取X年平均**（原「本益比取X年平均」，已更名） | 決定「1便宜價/3合理價/4昂貴價」計算時 EPS 要取近幾年平均 | 3／5／10 年 |
| **BPS取X年平均**（原「淨值取X年平均」，已更名） | 決定同上，BPS 要取近幾年平均 | 3／5／10 年 |
| 設定備註 | 依上面兩個設定自動帶出預設文字（例：「EPS取近5年平均、BPS取近3年平均」），**使用者可自由編輯覆蓋** | 文字（系統預帶值＋可編輯） |
| 目標價選擇 | 決定「目標價」欄位要對應顯示哪一檔 | 1便宜價／2次便宜／3合理價／4昂貴價／5超貴價／6爆炸貴 |

### 3.2 市場資料類欄位（唯讀，由資料源取得）

| 欄位 | 說明 |
|---|---|
| 目前成交價 | 最新成交價（原始收盤價） |
| 10年高／10年低 | 近10個完整曆年，盤中實際最高／最低價 |
| 十年平均殖利率 | 定義見「2. 計算基準」 |
| 股利發日 | **除息交易日**（Ex-Dividend Date，非撥款入帳日）；取所有已公告除息日中**最近的未來一筆**，若尚未公告任何未來除息日則改用**最近的過去一筆**（決策見 DEC-14） |
| 上次更新時間 | 本畫面所依賴的市場資料最後一次向 FinMind 同步的時間；取多個資料集同步時間中**最早**的一筆，避免其中一個剛更新的資料集誤導使用者（決策見 DEC-19，資料庫細節見 DB-01） |

### 3.3 估值計算類欄位

```
目標價          = 依「目標價選擇」對應到 1~6 其中一檔的值
加一年股利價     = 目標價 × (1 + 十年平均殖利率)
與目標價差比     = 目前成交價 ÷ 目標價 − 1                              [DEC-1]
前目標價出現     = 近10年中，最近一次「該年度最低價 ≤ 目標價」的年份
X年內買回        = LOG(1 + 與目標價差比) ÷ LOG(1 + 十年平均殖利率)
                  若與目標價差比 ≤ 0（現價已達或低於目標價），顯示「0／已達成」而非負值
賣賺幾年         = (目前成交價 − 3合理價) ÷ 3合理價 ÷ 十年平均殖利率      [與「X年內買回」刻意採不同模型，見DEC-7]
                  若結果 ≤ 0（現價尚未超過合理價），顯示「尚未獲利」而非負值

1便宜價  = (PER便宜價 + PBR便宜價) ÷ 2
           PER便宜價 = EPS(X年平均) × 10年平均最低PER
           PBR便宜價 = BPS(X年平均) × 10年平均最低PBR
2次便宜  = (1便宜價 + 3合理價) ÷ 2
3合理價  = (PER合理價 + PBR合理價) ÷ 2                                  [原表筆誤已修正]
           PER合理價 = EPS(X年平均) × 10年平均PER
           PBR合理價 = BPS(X年平均) × 10年平均PBR
4昂貴價  = (PER昂貴價 + PBR昂貴價) ÷ 2                                  [原表筆誤已修正]
           PER昂貴價 = EPS(X年平均) × 10年平均最高PER
           PBR昂貴價 = BPS(X年平均) × 10年平均最高PBR
5超貴價  = (10年高 − 4昂貴價) × 1/3 + 4昂貴價                           [DEC-2：維持原公式]
6爆炸貴  = (10年高 − 4昂貴價) × 2/3 + 4昂貴價
```

### 3.4 AI 建議欄位（畫面最下方）

| 欄位 | 說明 |
|---|---|
| AI投資建議 | 按下「AI投資建議」按鈕才觸發，呼叫 Groq Compound Mini，結合內建 Web Search、基本面與技術面資料產生短中期投資建議，**限制200字以內**。頁面載入時顯示上次產生的結果，不會自動重打；旁邊顯示產生此建議的**上次更新時間**（決策見 DEC-22、DEC-23，資料庫細節見 DB-01） |

### 3.5「更新」按鈕行為

畫面上有一顆「更新」按鈕，按下後重新向 FinMind 抓取本畫面除「3.1 設定類欄位」以外的所有市場資料
（目前成交價、10年高/低、十年平均殖利率、股利發日、EPS/BPS 相關統計等），並更新「上次更新時間」。
**不含**「3.1 設定類欄位」與「3.4 AI投資建議」——AI建議由獨立的按鈕觸發（決策見 DEC-20）。

## 4. 決策紀錄（Decision Log）

- **DEC-1**：與目標價差比 = 現價/目標價 − 1。現價>目標價時為正（代表買貴了，對應「X年內買回」= 靠填息 cost down 回本所需年數）；現價≤目標價時，X年內買回顯示「0／已達成」。
- **DEC-2**：5(超貴價)/6(爆炸貴) 暫不與1~4檔的PER/PBR估值法統一方法論，維持「10年高低線性外插」原公式，先求可用，待實際使用後再評估是否受極端年度高點影響過大。
- **DEC-3**：「本益比取X年平均」「淨值取X年平均」更名為「EPS取X年平均」「BPS取X年平均」，名稱直接對應公式實際使用的變數，避免與「10年平均PER/PBR」（固定10年、不受此設定影響）混淆。
- **DEC-4**：10年高低、PER、PBR 相關統計一律使用原始收盤價，不做除權息還原，取資料與實作皆較簡單。
- **DEC-5**：「設定備註」系統依設定自動帶出預設文字，但**使用者可自由編輯覆蓋**，非唯讀。
- **DEC-6**：「投資策略」與「設定備註」是角色不同的獨立欄位——投資策略記錄使用者整體投資邏輯/長期計畫，設定備註僅對應當下 EPS/BPS 取X年平均的設定說明，兩者不合併。
- **DEC-7**：「賣賺幾年」（線性比例）與「X年內買回」（LOG複利）刻意保留兩種不同數學模型，不強制統一方法論。
- **DEC-8**：「股利發日」若同一年度配息多次（半年配／季配），顯示**最近一次**的發放日，暫不支援多筆並列。
- **DEC-9**：EPS／BPS 取X年平均，僅採用**已完整公告的年度數字**，不納入尚未滿一年的 TTM 數字。
- **DEC-10**：10年高/10年低、及「前目標價出現」用的年度最低價，改用當日盤中實際最高/最低價，取代原 DEC-4 的「一律收盤價」；PER/PBR(均)與年度殖利率換算仍使用收盤價。（依據：FinMind 資料來源查證，見 SA-02）
- **DEC-11**：十年平均殖利率改採 FinMind TaiwanStockPER 的 dividend_yield 官方欄位（先年度平均、再10年平均），不再自行用現金股利÷均價手算。（見 SA-02）
- **DEC-12**：「股利發日」實際對應除息交易日（Ex-Dividend Date），並非撥款入帳日；修正原欄位定義。（見 SA-02）
- **DEC-13**：資料來源映射表中「10年平均PER/PBR落點」為重複列，已移除。（見 SA-02）
- **DEC-14**：「股利發日」的「最近一次」定義修正為——優先取**最近的未來**除息日（已公告、尚未發生）；若目前沒有任何已公告的未來除息日，才退回取**最近的過去**除息日。取代原 DEC-8「一律顯示最近一次」未區分過去/未來的措辭。
- **DEC-15**：已確認 FinMind TaiwanStockFinancialStatements 的 EPS 為**單季**數字（非累計），年度EPS = 該年度 Q1+Q2+Q3+Q4 四季加總；原列於 SA-02 的「重大實作風險」已解除。（見 SA-02）
- **DEC-16**：「產業別」欄位確定用途——UI 上顯示於股票名稱旁的小字，作為識別資訊，不參與任何估值計算，也不在畫面上獨立成一個資料區塊。
- **DEC-17**：目標價、1~6檔價位、與目標價差比、X年內買回、賣賺幾年等計算結果**不落地存資料庫**，每次請求時從資料庫已快取的原始資料即時運算；只有 FinMind 抓回來的原始資料才存庫。（詳見 DB-01）
- **DEC-18**：「目前成交價」每次進頁面自動更新 = 先查資料庫今天有沒有這支股票的最新價格，沒有才打一次 FinMind 抓最新價格；同一天內重複進頁面不會重複打 API。（詳見 DB-01）
- **DEC-19**：「上次更新時間」取本畫面依賴的多個 FinMind 資料集同步時間中的**最小值**（最保守的一筆），股票基本資料（名稱/產業別）不列入計算。（詳見 DB-01）
- **DEC-20**：「更新」按鈕重抓除「3.1 設定類欄位」與「3.4 AI投資建議」以外的所有市場資料；逐年型資料採回補窗口＋delta抓法，低頻型資料（股利/財報）直接整批重抓。（詳見 DB-01）
- **DEC-21**：目前確定不做使用者登入，設定資料暫不加使用者欄位，先做單一使用者版本；未來要加登入再擴充，不影響其他資料。
- **DEC-22**：「AI投資建議」結果存庫，每支股票只保留最新一筆；頁面載入顯示舊建議＋上次更新時間，不自動重打 Groq，只有按鈕觸發才重新產生，保護額度。（詳見 DB-01）
- **DEC-23**：Groq Compound Mini 視需要使用內建 Web Search 取得時事資訊；基本面/技術面資料直接重用畫面已算好的欄位，不另外重查；回覆限制**200字以內**。（詳見 DB-01）
- **DEC-24**：股價與PER/PBR這兩類逐日資料集，不存逐日原始資料，改成應用程式端聚合成「年度」統計後只存年度粒度，大幅節省儲存空間；財報/股利資料量小，不受影響。取捨：未來若要做需要逐日資料的功能（如股價走勢圖），屆時需另外向 FinMind 重新抓逐日資料。（詳見 DB-01）
- **DEC-25**：所有資料表統一加上建立/更新時間與操作人員四個稽核欄位，並移除與此意義重複的個別時間戳欄位。（詳見 DB-01）

## 5. 開放問題（待後續確認，不影響本次先求可用的開發）

- 數值精度／四捨五入規則（價格、百分比各顯示到小數第幾位），待前端畫面規格確認後補上。
- 「當年/近10年 現金股利、股票股利」原始金額是否要保留供未來股利明細畫面使用（見 SA-02 開放問題）。
